## Review disposition

- Accepted findings were implemented only where they were supported by the live route and source.
- Unsupported audit suggestions—invented phone/Zalo contact paths, removal of the hero feature bar, duplicate section-id claims, and token changes that conflicted with the project theme engine—were rejected.
- For `Threat`, the audit's visible progress and responsive reflow findings were accepted. Duplicate summary cards, thumbnail controls, and the claim that the pinned sequence behaved like a modal were rejected after live preview inspection.
- For the typography pass, the audited `text-h1` section tier was accepted for technical details, gallery, measurement, and FAQ. Unrelated preview changes to copy, route order, content, and interactions were rejected.
- The supplied AWWWARDS component library informed the transparent glass header and stacked architectural process sequence; both were adapted to the existing GSAP, Lenis, Tailwind v4, and reduced-motion conventions.
